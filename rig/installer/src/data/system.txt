# Paquetes de sistema por perfil y por gestor de paquetes.
# bootstrap.sh detecta el gestor (apt | pkg | brew) y usa la columna adecuada.
#
# Formato por linea (separado por espacios/tabs):
#   <id>  <perfil>  <apt>  <pkg>  <brew>
#
#   perfil: both | dc1 | vps
#   Un valor '-' en una columna significa "no instalar en ese gestor".
#   <id> es solo un identificador legible (no se instala directamente).
#
# Estado de verificacion:
#   apt  -> VERIFICADO en Debian 13 (VPS real).
#   pkg  -> nombres segun catalogo Termux; CONFIRMAR en la tablet.
#   brew -> nombres segun Homebrew; CONFIRMAR en Mac.
# Lineas que empiezan con # se ignoran.
